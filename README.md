# 멸종위기종 전자야장 (식물·곤충)

멸종위기 야생생물 현지조사표(식물·곤충)를 휴대폰에서 전자로 기입하고, 내 조사기록을 검색·통계 분석하는 설치형 웹앱(PWA)입니다.

## 파일 구성
```
index.html               앱 본체 (모든 화면·기능)
registry.json            메타데이터 레지스트리 (데이터 요소·코드목록·표준화 이슈)
manifest.webmanifest     앱 설치 정보 (이름, 아이콘, 색상)
sw.js                    오프라인 동작용 서비스워커
icons/                   앱 아이콘 (남색 바탕 + 한반도 + 점 3개)
SERVER_API.md            향후 서버 연동 설계 초안 (배포에 필수 아님)
```
**index.html, registry.json, manifest, sw.js, icons를 모두 같은 위치에 올려야** 설치·오프라인·표준화 기능이 동작합니다.

## GitHub Pages 배포 (약 5분)
1. GitHub에서 **New repository** 생성 (예: `esurvey`, Public)
2. **Add file → Upload files**로 압축을 푼 파일과 `icons` 폴더를 그대로 끌어다 놓고 **Commit**
3. **Settings → Pages → Branch: `main` / `(root)` → Save**
4. 1~2분 뒤 `https://<아이디>.github.io/esurvey/` 주소가 생성됩니다. 이 주소를 조사원에게 공유하세요.

## 휴대폰에 설치
- **안드로이드 (크롬)**: 주소 접속 → 오른쪽 위 **설치** 버튼 → 설치
- **iPhone (크롬, iOS 16.4 이상)**: **설치** 버튼을 누르면 안내가 뜹니다 → 주소창의 공유(□↑) → **홈 화면에 추가**
  (애플 정책상 iOS는 원클릭 설치를 지원하지 않습니다.)

## 주요 기능
- **지도**: OpenStreetMap(도로) / Esri(위성) 전환, 조사지점에 조사일자와 국명 표시
- **+ 버튼**: 식물(6개 탭)·곤충(5개 탭) 선택 → 전자야장 (현지조사표 항목 그대로, 서식지(처) 유형은 1개만 선택)
- **자동 기입**: 버튼 하나로 조사일자, 시각, 날씨, 기온(Open-Meteo), 행정구역(Nominatim), 경위도(도/분/초), 고도
- **좌표값 취득원**: 반드시 1개만 선택 (단일 선택)
- **☰ 메뉴**: 전체 항목 검색 · 기술통계(조사자/분류군/기간/조사종명 필터, 평균·SD·중앙값, 박스플롯, 월별·지역별, 위협요인·서식지 빈도) · CSV/PDF/백업
- **중첩 좌표**: 같은 위치나 가까운 기록은 원형으로 펼쳐 지시선으로 연결, 10건 초과는 묶음 버튼(누르면 확대 또는 목록)
- **PDF 저장**: 식물/곤충 야장 전체, 개별 야장(상세보기), 통계 보고서. 인쇄 화면에서 ‘PDF로 저장’ 선택
- **현장 보조**: 휴대폰 나침반으로 방위, 경사계로 경사도 측정, 입지위치도 그리기, 사진 첨부
- **임시저장**: 작성 중 앱이 닫혀도 다음에 이어쓰기 가능

## 메타데이터 레지스트리
`registry.json`이 전자야장 데이터의 표준 정의서입니다. 앱은 이 파일에서 항목명·선택지·필수 여부·허용범위를 읽어 입력 화면을 구성하고, 저장할 때 표준 요소ID·코드값으로 변환해 검증합니다.

- **구성**: 데이터 요소 82개(요소ID, 국·영문명, 정의, 자료형, 단위, 허용범위, 의무성, 원본 야장 항목, Darwin Core 용어, 민감도) · 코드목록 29개(250개 코드) · 표준화 이슈 12건
- **표기 통합**: 식물·곤충 조사표의 같은 의미 다른 표기(예: 구글지도/구글맵, 사태/산사태, 서식가능/가능)를 단일 코드로 통합. 화면에는 각 조사표 표기를 그대로 표시
- **저장 시 검증**: 필수값 누락, 허용범위 이탈, 코드목록 외 값, 좌표 취득원 누락, 종명 오기(종 코드표 등록 시) 등을 경고. 결과는 기록에 함께 저장
- **☰ → 메타데이터**: 요소·코드목록 조회, 표준화 이슈, 개정 제안, 전체 재검증, 자료사전·코드목록·Darwin Core·표준 데이터 패키지 내보내기, 종 코드표 가져오기
- **개정 절차**: `registry.json`을 수정할 때는 `registry.version`을 올리고(예: 1.0.0 → 1.1.0) `changeLog`에 내용을 적은 뒤 GitHub에 올립니다. 앱은 더 높은 버전을 자동으로 받아 적용하며, 기존 기록은 메타데이터 › 재검증으로 새 버전에 맞출 수 있습니다.
- **서버 대비**: 기록마다 고유 ID·수정 차수·작성 기기·조사자 ID·동기화 상태를 저장합니다. 서버 연동 시 표준 데이터 패키지 형식 그대로 전송하도록 설계했습니다(`SERVER_API.md`).

## 화면 캡쳐 방지에 관하여
웹앱은 휴대폰 OS의 캡쳐 버튼(전원+볼륨)을 원천 차단할 수 없습니다. 대신 아래 방식으로 보호합니다.
- 감지 가능한 캡쳐 시도에서 경고 메시지 표시와 지도 가림: PC 캡쳐 키, 세 손가락 캡쳐 제스처, 지도 길게 누르기, 인쇄
- 앱 전환 시 지도 가림 (최근 앱 미리보기 노출 방지)
- 조사자명·시각이 들어간 워터마크로 유출 시 출처 추적

## 자료 보관 주의
야장 자료는 **각 휴대폰 안에만** 저장됩니다(서버 전송 없음). 브라우저 데이터를 삭제하거나 앱을 지우면 사라지므로 조사가 끝나면 **☰ → 설정·백업 → 전체 백업 파일**을 꼭 내보내 두세요.

## 업데이트 방법
`index.html`을 수정해 다시 올린 뒤, `sw.js` 첫 줄의 `VER` 값을 올려 주세요(현재 `v1.2.0`). 앱을 다시 열면 새 버전이 적용됩니다.
